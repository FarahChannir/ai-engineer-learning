Purpose of This Review

This review ti set all core classic machine learning algorithms to be a one mental model.
The objective is to answer those questions : when, why, and how each algorithm should be used, not just  focusing on mathematical derivations or implementation details. 


---------------------------------------------------

Main Axes :

We can compare the algorithms using the following axes:

Learning Type: Supervised vs Unsupervised

Problem Type: Regression, Classification, Clustering

based Mechanism: Function-based, Distance-based, Boundary-based, Centroid-based

Assumptions: Linearity, separability, distance validity, cluster shape

Primary Trade-off: Simplicity vs flexibility vs performance

--------------------------------------------------------------------------------------------

Algorithm Summaries (Concise)
Linear Regression

Type: Supervised – Regression

Output: Continuous value

Core Idea: Fits a linear function minimizing squared error

Strength: Simple, fast, interpretable

Limitation: Cannot model non-linear relationships

Typical Use: Price prediction, trend estimation
